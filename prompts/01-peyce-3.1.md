C. FIVE ORIGINAL, OPTIONAL CHECK-IN QUESTIONS

Proposed original copy (these are not STAI items or validated assessment items):

Q1. "How easy is it to let your shoulders and jaw soften right now?"
Green: "Easy" | Orange: "Takes some effort" | Red: "Hard right now"
Purpose: a stated body-tension cue, not a diagnosis.

Q2. "How easy is it to set a repeating thought aside for a moment?"
Green: "Easy" | Orange: "It comes back" | Red: "It keeps pulling me in"

D. EXPLAINABLE MATCHING, NOT AN ANXIETY SCORE

Define the rule table and worked fictional examples before prototyping the recommendation. Use the answer content and explicit preferences, not how many red faces there are. None of the supplied studies validates this five-question matching policy. Label it a design heuristic, not a psychological test or treatment recommendation.

Rules in order:
1. A deliberate current exercise choice overrides the suggested path. The person may always stop or select neither.
2. "I'd rather not" excludes that skill from automatic recommendation. If both are declined, offer finishing or voluntary exploration, not pressure or a forced default. If only one is declined and the other explicitly comfortable, suggest the comfortable option.
3. When one activity is explicitly comfortable and the other uncertain, favor the expressed comfort, explaining that reason. A skipped preference is unknown, not dislike or permission.
4. When both activities are comfortable, body-tension responses can favor breathing; repetitive-thought/present-focus responses can favor grounding. Specify deterministic, versioned tie and partial-answer behavior. For a compact implementation, map Q1-Q3 answer severity to 0/1/2; compare Q1 with max(Q2,Q3) ONLY when all three are answered. This is a private routing heuristic, not a total anxiety score or validated weighting. Do not display the numbers.
5. If that comparison ties, is all zero, or lacks necessary answers, do not invent certainty: offer both with equal prominence. A direct expressed comfort preference can still supply a transparent suggestion independently of the comparison.
6. No recommendation may be justified using a skipped answer. Never infer emotion from clicking speed, cursor paths, hesitation, device, face color alone, or a saved session. Historical preference may be offered later, never override today's answer.

Navigate to the suggested exercise's ready screen with a short reason, a Start button, and an easy alternative. Do not create another long result funnel or start a timer without a deliberate Start action.

Example body-tension path: Q1 red, Q2 green, Q3 green, Q4 green, Q5 green => breathing. Explanation should cite the selected body-tension response and comfort with breathing, not declare anxiety.
Example present-focus path: Q1 green, Q2 red, Q3 orange, Q4 green, Q5 green => grounding.
Preference override: same body-tension answers but Q4 red and Q5 green => grounding.
Both preferences red => neither forced.
All skipped or an uninformative tie => equal exercise choice.
Back-changing Q4 to red must remove a previously suggested breathing path.
