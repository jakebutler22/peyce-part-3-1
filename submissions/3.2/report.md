## Genuine model contribution and application authority

Peyce's constrained conversation contains original assistant questions and selected user labels/skips, rather than open text. The backend provides actual committed turns, deliberate choice, the approved deterministic result and eligible question references. The model may select only an opening, relevant references and a closing. The application inserts exact answer labels and approved copy, rejects extra fields/wrong reasons/skipped references and limits the constructed text to 240 characters. Model output cannot diagnose, score, select a skill, navigate, change timing or control support. The questions/matching policy remain versioned, unvalidated design heuristics.

For actual fictional answers **[2,0,0,0,0]**, the model selected `opening_id=reflect`, `reference_ids=[body,breathing]`, `closing_id=choice` and the unchanged `body-cue` reason. The displayed acknowledgment was:

> You selected shoulders/jaw: “Hard right now”; breathing: “Comfortable”. A gentle breathing rhythm is one option. You can choose or finish.

That wording is application-constructed from the model's validated selections, not unrestricted generated counseling. It reflects the actual current body and breathing-comfort turns. The request was **`33d3d4a4-4715-41da-ad79-e3ab252b0826`**, ready revision **8**, prompt **`peyce-acknowledgment-1.1`**, HTTP **200**, `finish_reason=tool_calls`, **31 completion tokens**, **zero reasoning tokens**, `status=validated`, `stale=false`. The actual response identified the exact authorized free model. SQLite contains the matching assistant turn with source **`validated-openrouter-acknowledgment`**. The same session subsequently finished revision 11; history correctly labels the acknowledgment's earlier ready revision.

The restricted model role trades expressive conversation for inspectable authority. Its added value over fixed rule copy has not been evaluated. One successful case demonstrates actual integration, not broad model reliability; instructor acceptance of structured button-led conversation remains a human interpretation question.
